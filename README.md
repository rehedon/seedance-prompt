# Seedance视频提示词


一个面向 **Seedance / 即梦 2.0 与 2.5** 的视频提示词 Skill。

它可以把一句创意、脚本片段、镜头描述，或图片、视频、音频等参考素材，整理成结构清晰、可直接复制到 Seedance 使用的视频提示词。

## 功能

- 根据用户指定的版本，在 Seedance 2.0 与 2.5 规则之间自动切换。
- 将简单创意扩写成包含主体、场景、动作、摄影、表演、声音和限制项的完整提示词。
- 支持文生视频、全能参考、首尾帧、视频延长、智能编辑、超长视频、白模与绿幕等任务。
- 自动处理人物身份、服装、道具、空间位置、光线和动作相位的连续性。
- 支持图片、视频和音频素材编号，例如 `@图片1`、`@视频1`、`@音频1`。
- 可以输出带简短说明的版本，也可以只输出可直接复制的纯提示词。
- 支持“一个视频内多镜头”：在同一条提示词里写明镜头顺序和硬切位置，避免默认生成一镜到底。
- 默认先建立角色、场景、道具和风格图片资产库，再为每条视频列出生成时需要上传的图片及关联顺序。

本 Skill 专注于生成与优化视频提示词。如果需要完整导演分镜、镜头表或全片生成任务规划，建议改用专门的分镜 Skill。

## 默认工作流：先规划图片资产，再生成视频

每次根据创意或剧本生成提示词时，Skill 会先输出：

1. 图片资产总表，例如角色 `CH-01`、场景 `SC-01`、道具 `PR-01`、特效/风格 `FX-01`。
2. 每项待制作资产的独立图片生成提示词。
3. 每条视频生成任务所需的图片和上传顺序。
4. 映射好 `@图片1`、`@图片2` 后的 Seedance 视频提示词。

项目资产编号在全片保持不变，但 `@图片N` 按每条视频实际上传顺序临时生成。例如：

```text
本任务生成时上传：
① CH-01 主角定妆图 → @图片1
② SC-01 老街场景图 → @图片2
③ PR-01 旧信封 → @图片3
```

这表示图片先按资产提示词制作；等真正生成这条视频时，再按上述顺序上传并关联。Skill 不会把尚未制作的图片假装成已上传素材。

## Seedance 2.0 与 2.5 的处理差异

### Seedance 2.0

- 单次生成按 4–15 秒规划。
- 片内多镜头通常建议 15 秒内安排 2–4 镜，并明确写“禁止一镜到底”“硬切至下一镜头”。
- 用户要求一个视频内切镜时，所有镜头会封装进同一个提示词；用户要求逐镜生成时，才拆成多个视频任务。
- 超过 15 秒的内容会在动作阶段、情绪转折或台词停顿处自动拆分。
- 拆分后的提示词会继承上一段尾帧，避免人物、道具和动作突然重置。
- 不会误用 Seedance 2.5 的超长视频、白模或高级编辑能力。

### Seedance 2.5

- 普通生成按 4–30 秒规划。
- 30–180 秒内容可按“超长视频”模式组织宏观段落与时间轴。
- 支持时间戳控制、视频延长、智能编辑、空间视角修改、BGM 移除、白模、多宫格、绿幕和视频转场等模式。
- 编辑任务会明确区分“保持不变”和“只修改”的内容。

## 安装

### 让 Codex 帮你安装

把本仓库地址交给 Codex，并告诉它：

```text
请帮我安装这个 GitHub 仓库中的 Skill：
https://github.com/rehedon/seedance-prompt
```

### 手动安装

1. 下载或克隆本仓库。
2. 将整个仓库文件夹复制到：

```text
~/.codex/skills/seedance-prompt
```

3. 重新打开 Codex，或重新载入 Skills。

安装后的目录结构应为：

```text
seedance-prompt/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── references/
    ├── asset-workflow.md
    ├── seedance-2.0.md
    └── seedance-2.5.md
```

## 调用名称

```text
$seedance-prompt
```

## 使用示例

### 生成 Seedance 2.5 提示词

```text
使用 $seedance-prompt。

Seedance 2.5，16:9，15秒。
雨夜古城，一名女剑客在屋顶躲避追兵，写实武侠电影感。
输出纯提示词。
```

即使写了“输出纯提示词”，默认仍会保留图片资产提示词和逐任务关联，只省略解释性分析。只有明确写“不要资产规划”时才会跳过该环节。

### 为 Seedance 2.0 自动拆分长内容

```text
使用 $seedance-prompt。

Seedance 2.0，把下面的30秒剧情转成视频提示词。
如果超出单次时长，请自动拆分，并保持人物和动作连续：
……
```

### 让 Seedance 2.0 在一个视频内切镜

```text
使用 $seedance-prompt。

Seedance 2.0，16:9，15秒，一个视频里包含3个镜头，不要一镜到底：
老人走到旧邮筒前，把信投入缝隙，最后切到邮筒内部旧信堆的特写。
输出纯提示词。
```

Skill 会把这些镜头写进同一个代码块，用“硬切至镜头2”等指令明确切镜。Seedance 2.0 的切镜属于生成式软控制；如果仍未切镜，可减少镜头数量或改为逐镜生成后期剪辑。

### 使用参考图片和视频

```text
使用 $seedance-prompt。

Seedance 2.5，全能参考，20秒。
@图片1控制人物面容、发型和服装；
@图片2控制雨夜街道场景；
@视频1只参考奔跑动作和跟拍节奏。
人物穿过拥挤夜市逃离追兵，不要字幕，不要BGM。
```

### 智能编辑

```text
使用 $seedance-prompt。

Seedance 2.5 智能编辑。
保持人物身份、服装、台词和背景建筑不变，
只把晴天改成暴雨夜景，并增加真实的积水反光和雷声。
```

### 视频延长

```text
使用 $seedance-prompt。

Seedance 2.5，延长现有视频8秒。
继承原视频尾帧中人物的奔跑方向、速度和镜头运动，
让人物冲进巷口后急停回头，远处传来追兵脚步声。
```

## 推荐提供的信息

为了获得更稳定的结果，建议尽量提供：

- 模型版本：Seedance 2.0 或 2.5
- 目标时长与画幅
- 主体、地点和核心事件
- 视觉风格与摄影方式
- 台词、环境声和是否需要 BGM
- 每个参考素材的具体职责
- 不希望出现的内容

如果信息不完整，Skill 会在不改变创意的前提下补齐常用设置；只有缺失内容会实质改变任务时，才会询问一个简短问题。
